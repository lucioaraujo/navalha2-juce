Tutorial

The ten chapters of the tutorial Navalha 2 carries under its TUTORIAL button, from the first source to recording and help.

1 · START

Load or drag a WAV/AIFF to SOURCE A or B. Choose a region, divide it into slices, then press PLAY. The original recording is never edited.

2 · LIBRARY

Before starting a project, create a dedicated folder (for example Project_Name/Sources) and place only the material you intend to use there. AUDIO LIBRARY accepts WAV/WAVE and AIFF/AIF audio, and scans the selected folder and its subfolders, up to 512 files; MP3, FLAC, OGG and M4A are not source formats in this version. A clean folder prevents unrelated material from appearing. Use LOAD A/B or drag a file directly to the desired waveform lane.

3 · REGION

SELECT REGION defines the working area. WHOLE restores the complete source. PLAY SLICE auditions without modifying the file.

4 · SLICES

Divide the region into 4–64 slices, refine START/END in EDIT SLICE, or add non-destructive cuts with BLADE.

5 · PATTERN

The eight cells define slice order. RANDOM, INTERLEAVE, FORWARD, REVERSE, ZERO and GAP create or reshape patterns.

6 · SOUND

TIME sets BPM and timing behavior. HERITAGE PITCH provides the original 24 positions. SOURCE MIXER controls A/B level, pan, width and balance before MASTER.

7 · AUTO PERFORMER

ASSISTED PERFORMER makes bounded decisions from enabled vocabularies. Locks protect choices. PLAY, STOP and REC always remain human.

8 · PROJECTS

SAVE PROJECT stores state and source references. SAVE PORTABLE creates a Project v2 ZIP with copied sources for transport to another computer.

9 · REC / RESAMPLE

REC captures the real stereo MASTER. Finalized recordings enter TAKE TIMELINE, where metadata can be reviewed and a take can return as SOURCE A or B.

10 · HELP

Activate LEARN and move the pointer over a control. Its explanation appears in the fixed Activity Log panel without covering the instrument.
