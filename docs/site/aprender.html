Learn

Every control of Navalha 2 and what it does: the LEARN text the app shows in its Activity Log when you point at a control.

AUDIO ENGINE

Shows the real audio-device connection. Click to open audio settings.

OPEN PROJECT

Opens a Navalha project while leaving the referenced source recordings untouched.

SAVE PROJECT

Saves the current state and source references; it does not render audio.

SAVE PORTABLE

Creates a self-contained Project v2 ZIP with copies of SOURCE A and B.

LEGACY I/O

Imports or exports the historical .nvl and .ptn files. A legacy .nvl records only a sample name, so load SOURCE A manually after import.

PLAY

Starts the current pattern and sequencer.

STOP

Stops playback and safely finalizes an active recording.

RESET

Returns the sequencer cursor and transport clock to the first step.

REC

Starts or finalizes recording of the real stereo MASTER output. Recording stops automatically after five minutes.

TRANSPORT CLOCK

Shows elapsed playback or recording time.

AUDIO LIBRARY

Browse source material, then load or drag a WAV/AIFF to SOURCE A or B.

SEARCH FILES

Filters the visible library list by file name; it never changes or deletes a file.

LIBRARY PREVIEW

Auditions the selected WAV/AIFF independently at a safe level. It does not load SOURCE A/B or alter the file.

ACTIVITY LOG

Keeps the four most recent messages. COPY exports the text; CLEAR empties only this view.

WAVEFORM

Shows the active source. Drag to select a region; BLADE clicks create cuts.

SELECT REGION

Dragging the waveform defines the larger region used to make slices.

EDIT SLICE

Edits the START and END boundaries of the selected slice.

SLICE CONTROLS

Chooses SOURCE A/B and a slice, then adjusts START/END. SET commits the edit; PLAY SLICE auditions it.

BLADE

Each waveform click adds a non-destructive cut inside the region.

DIVIDE REGION

Creates 4, 8, 16, 32 or 64 equal slices inside the selected region.

BPM

Sets sequencer tempo from 20 to 400 beats per minute.

PATTERN

Selects one of the eight step-pattern memories.

PATTERN ORDER

Builds or reshapes the eight-step order from SOURCE A, SOURCE B and GAP cells.

LIVE GESTURES

Applies reversible structural gestures or short fragment actions to the current performance.

TIMING

GRID is regular, FREE varies durations, and JITTER moves intervals around the grid.

HERITAGE PITCH

Uses the historical 24-position range from −12 through +11 semitones.

ASSISTED PERFORMER

Makes bounded musical decisions but never controls PLAY, STOP or REC.

FORM

Directs the piece through INTRO, DEVELOP, RUPTURE, CLIMAX and EXIT scenes.

TRACE XY

Records and optionally loops control movement; it does not record audio.

MOTIF MEMORY

Stores, recalls and varies reusable musical snapshots with independent locks.

SOURCE MIXER

Balances SOURCE A/B before pitch and sends their stereo sum to MASTER OUTPUT.

SOURCE LEVEL

Sets source gain before the stereo sum: 0 is silent, 1.00 is unity and values above 1 add gain.

SOURCE PAN

Places one source in the stereo field: −1 is left, 0 is centre and +1 is right.

SOURCE WIDTH

Controls stereo width: 0 folds to mono, 1 preserves the source and 2 exaggerates side information.

SOURCE MUTE

Silences only this source without changing its level setting.

SOURCE SOLO

Auditions this source without the other one. If both are soloed, both remain audible.

A/B BALANCE

Cross-balances the mixed sources: −1 favours A, 0 keeps both and +1 favours B.

MASTER / TECHNICAL OUTPUT

MASTER shapes the instrument creatively. OUTPUT TRIM only attenuates −24 to 0 dB before the true-peak limiter; MUTE uses a click-free ramp. Device reconnect resumes from silence.

RECORD FORMAT

Chooses PCM16, PCM24 or FLOAT32 for the next stereo MASTER recording.

VIRTUAL VOICES

Adds two parallel internal voices that reuse SOURCE A/B with safe headroom.

TAKE TIMELINE

Opens recording history, review metadata and TAKE-to-SOURCE actions.

DUAL MONITOR

Moves live performance to the second display while the main display keeps editing and production controls.

MASTER WINDOW

Opens the separate offline mastering and album-rendering workspace.

TAKES / MASTER

Opens the linked production workspace: review takes on the left and prepare track or album masters on the right.

LANGUAGE

Changes contextual help and tutorial text between English, Portuguese, French and Spanish.

TUTORIAL

Opens the ten-chapter guide inherited from the PD v0.28.1 workflow.

ABOUT

Shows version, reference build, authorship and license information.

LEARN

When active, moving over or focusing a control explains it in the fixed Activity Log panel.

VIEW

Chooses automatic sizing or a larger interface scale. Small displays keep scrolling available.
