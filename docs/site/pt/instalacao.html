Instalação

Como instalar o Navalha 2 no Windows, no macOS e no Linux, e o que ele pede do computador.

Baixar

Versão 0.2.2, a atual. Os avisos de segurança do Windows e do macOS são esperados e aparecem só na primeira vez.

Windows · .exe Windows · .zip macOS · .dmg Linux · .deb Linux · AppImage Linux · .tar.gz

Windows

  1. Baixe navalha2-<versão>-win64.exe e abra.
  2. O Windows mostra "O Windows protegeu o computador": clique em "Mais informações" e depois em "Executar assim mesmo".
  3. Se pedir permissão de administrador, clique em "Sim".
  4. Clique em "Avançar" até o fim. O Navalha 2 fica no Menu Iniciar e na área de trabalho; cada versão nova substitui a anterior.

Sem instalar: descompacte navalha2-<versão>-win64.zip e abra Navalha 2.exe.

macOS

  1. Baixe navalha2-<versão>-Darwin.dmg. Ele serve para Mac Intel e Apple Silicon.
  2. Abra e arraste o Navalha 2 para Aplicativos.
  3. Abra o app. Na primeira vez, o macOS o bloqueia, porque ele tem assinatura ad hoc, sem o Developer ID pago da Apple. Clique em "OK".
  4. Libere o app uma vez: em Ajustes do Sistema → Privacidade e Segurança, clique em "Abrir Mesmo Assim" e confirme. No macOS 14 ou anterior: botão direito no app, no Finder → Abrir → Abrir.
  5. Na primeira gravação pelo microfone ou por uma interface de áudio, o macOS pede permissão: permita.

Se o botão não aparecer, use o Terminal. O comando tira a marca de quarentena que o macOS põe em todo arquivo baixado:

xattr -dr com.apple.quarantine "/Applications/Navalha 2.app"

Linux

  • Ubuntu 22.04+, Debian 12+, Mint 21+: dois cliques no .deb, ou sudo apt install ./navalha2_<versão>_x86_64.deb.
  • Outras distribuições, AppImage: torne-o executável (Propriedades → permitir executar, ou chmod +x) e abra.
  • Outras distribuições, .tar.gz: descompacte e rode ./install.sh, que instala para o seu usuário, sem root; ./install.sh --remove desfaz.

Requisitos

WindowsWindows 10 ou 11, 64 bits
macOS10.15 ou mais novo (Intel), 11 ou mais novo (Apple Silicon); um pacote Universal 2
Linuxx86-64 com glibc 2.35 ou mais nova; testado na abertura em Debian 12, Ubuntu 24.04, Fedora e Arch
Processador2 núcleos a 2 GHz; 4 núcleos modernos recomendados para uso musical
Memória4 GB; 8 GB ou mais recomendados (WAVs longos usam memória proporcional ao tamanho)
Disco300 MB para o app, mais as suas gravações
Tela1480 × 900 para a interface principal
Áudioqualquer saída estéreo; uma interface USB é recomendada para gravar

São valores de referência dos guias de requisitos do projeto, não medidos numa máquina de referência. Para outra coisa, escreva para rasgo.instruments@gmail.com.
