Installation

How to install Navalha 2 on Windows, macOS and Linux, and what it needs from the computer.

Download

Version 0.2.2, the current one. The Windows and macOS security warnings are expected and appear only the first time.

Windows · .exe Windows · .zip macOS · .dmg Linux · .deb Linux · AppImage Linux · .tar.gz

Windows

  1. Download navalha2-<version>-win64.exe and open it.
  2. Windows shows "Windows protected your PC": click "More info", then "Run anyway".
  3. If Windows asks for administrator permission, click "Yes".
  4. Click "Next" to the end. Navalha 2 is then in the Start menu and on the desktop; each new version replaces the previous one.

Without installing: unzip navalha2-<version>-win64.zip and open Navalha 2.exe.

macOS

  1. Download navalha2-<version>-Darwin.dmg. It works on Intel and Apple Silicon Macs.
  2. Open it and drag Navalha 2 into Applications.
  3. Open the app. The first time, macOS blocks it, because it is signed ad hoc, without a paid Apple Developer ID. Click "OK".
  4. Allow the app once: in System Settings → Privacy & Security, click "Open Anyway" and confirm. On macOS 14 or earlier: right-click the app in Finder → Open → Open.
  5. The first time you record from the microphone or an audio interface, macOS asks for permission: allow it.

If the button does not appear, use Terminal. The command removes the quarantine mark macOS puts on every downloaded file:

xattr -dr com.apple.quarantine "/Applications/Navalha 2.app"

Linux

  • Ubuntu 22.04+, Debian 12+, Mint 21+: double-click the .deb, or sudo apt install ./navalha2_<version>_x86_64.deb.
  • Other distributions, AppImage: make it executable (Properties → allow executing, or chmod +x) and open it.
  • Other distributions, .tar.gz: unpack it and run ./install.sh, which installs for your user, without root; ./install.sh --remove undoes it.

Requirements

WindowsWindows 10 or 11, 64-bit
macOS10.15 or later (Intel), 11 or later (Apple Silicon); one Universal 2 package
Linuxx86-64 with glibc 2.35 or newer; launch-tested on Debian 12, Ubuntu 24.04, Fedora and Arch
Processor2 cores at 2 GHz; 4 modern cores recommended for musical use
Memory4 GB; 8 GB or more recommended (long WAV files use memory in proportion to their size)
Disk300 MB for the app, plus your recordings
Screen1480 × 900 for the main interface
Audioany stereo output; a USB interface is recommended for recording

These are reference values from the project's requirement guides, not measured on a reference machine. For anything else, write to rasgo.instruments@gmail.com.
