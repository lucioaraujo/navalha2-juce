Installation

Comment installer Navalha 2 sous Windows, macOS et Linux, et ce qu'il demande à l'ordinateur.

Télécharger

Version 0.2.2, l'actuelle. Les avertissements de sécurité de Windows et de macOS sont attendus et n'apparaissent que la première fois.

Windows · .exe Windows · .zip macOS · .dmg Linux · .deb Linux · AppImage Linux · .tar.gz

Windows

  1. Téléchargez navalha2-<version>-win64.exe et ouvrez-le.
  2. Windows affiche « Windows a protégé votre ordinateur » : cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
  3. Si Windows demande l'autorisation d'administrateur, cliquez sur « Oui ».
  4. Cliquez sur « Suivant » jusqu'à la fin. Navalha 2 est alors dans le menu Démarrer et sur le bureau ; chaque nouvelle version remplace la précédente.

Sans installer : décompressez navalha2-<version>-win64.zip et ouvrez Navalha 2.exe.

macOS

  1. Téléchargez navalha2-<version>-Darwin.dmg. Il fonctionne sur les Mac Intel et Apple Silicon.
  2. Ouvrez-le et glissez Navalha 2 dans Applications.
  3. Ouvrez l'app. La première fois, macOS la bloque, car elle a une signature ad hoc, sans Developer ID Apple payant. Cliquez sur « OK ».
  4. Autorisez l'app une fois : dans Réglages Système → Confidentialité et sécurité, cliquez sur « Ouvrir quand même » et confirmez. Sous macOS 14 ou antérieur : clic droit sur l'app dans le Finder → Ouvrir → Ouvrir.
  5. Au premier enregistrement par le microphone ou une interface audio, macOS demande l'autorisation : acceptez.

Si le bouton n'apparaît pas, utilisez le Terminal. La commande retire la marque de quarantaine que macOS pose sur chaque fichier téléchargé :

xattr -dr com.apple.quarantine "/Applications/Navalha 2.app"

Linux

  • Ubuntu 22.04+, Debian 12+, Mint 21+ : double-cliquez sur le .deb, ou sudo apt install ./navalha2_<version>_x86_64.deb.
  • Autres distributions, AppImage : rendez-le exécutable (Propriétés → autoriser l'exécution, ou chmod +x) et ouvrez-le.
  • Autres distributions, .tar.gz : décompressez et lancez ./install.sh, qui installe pour votre utilisateur, sans root ; ./install.sh --remove annule.

Configuration requise

WindowsWindows 10 ou 11, 64 bits
macOS10.15 ou ultérieur (Intel), 11 ou ultérieur (Apple Silicon) ; un paquet Universal 2
Linuxx86-64 avec glibc 2.35 ou plus récente ; testé au lancement sous Debian 12, Ubuntu 24.04, Fedora et Arch
Processeur2 cœurs à 2 GHz ; 4 cœurs modernes recommandés pour l'usage musical
Mémoire4 Go ; 8 Go ou plus recommandés (les WAV longs occupent une mémoire proportionnelle à leur taille)
Disque300 Mo pour l'app, plus vos enregistrements
Écran1480 × 900 pour l'interface principale
Audiotoute sortie stéréo ; une interface USB est recommandée pour enregistrer

Ce sont des valeurs de référence des guides de configuration du projet, non mesurées sur une machine de référence. Pour autre chose, écrivez à rasgo.instruments@gmail.com.
